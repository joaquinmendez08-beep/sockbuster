Vista de Procesos

Checkout (RF02): valida carrito y stock; luego descuenta stock y genera el pedido en paralelo, y recién entonces confirma al cliente (sincronización).

sequenceDiagram
actor C as Cliente
participant UI as catalogo.html
participant JS as app.js
participant LS as localStorage
C->>UI: Pulsa Pagar
UI->>JS: pay()
JS->>JS: Validar carrito y stock
alt Carrito vacío o sin stock
JS-->>UI: Mensaje de error
else Datos válidos
par Descontar stock
JS->>LS: Guardar inventario
and Generar pedido
JS->>JS: Crear ID único y resumen
end
JS->>LS: Guardar pedido
JS-->>UI: Mostrar resumen con ID
UI-->>C: Pedido confirmado
end

Vista Física

Topología de despliegue: el navegador del cliente accede por HTTPS al CDN de GitHub Pages que sirve el sitio estático (RNF01 y RNF02). En línea punteada, la evolución escalable con API REST protegida por JWT y base de datos.
